# Task Manager

A simple task management app built with React and TypeScript.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks by status
- Search tasks
- Add and edit task time
- Submit forms with Enter

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
